# Prompt Engineering and Programming with OpenAI

Welcome to the **Prompt Engineering and Programming with OpenAI** course! This repository/guide serves as your central hub for navigating the self-directed learning journey developed by Hardeep Johar at Columbia University.

---

## ## Course Overview

This course is designed to bridge the gap between creative prompt engineering and technical implementation using OpenAI's powerful language models. Whether you are a developer looking to integrate AI into your tech stack or a strategist aiming to master LLM communication, this curriculum provides the tools necessary to excel in the field of Generative AI.

---

## ## Learning Structure

As a **self-directed course**, you have the flexibility to move at your own pace. The curriculum is delivered through:

* **Lectures:** Video and written content exploring core concepts.
* **Readings:** Deep dives into documentation, research papers, and best practices.
* **Assessments:** Knowledge checks to validate your understanding of the material.

## ## Development Tools (Optional but Recommended)

To get the most out of the programming sections, you should have access to:

1. An **OpenAI API Key**.
2. A Python environment (e.g., Jupyter Notebook, VS Code, or Google Colab).
3. Basic familiarity with REST APIs and JSON structures.
