# Module 1 Quiz
### *Building Customized LLMs with OpenAI — Columbia Plus*

This directory contains the final assessment for **Module 1: Retrieval-Augmented Generation (RAG)**. This quiz is designed to reinforce your understanding of the technical core concepts covered throughout the first eleven units—from vector search algorithms to knowledge graph architectures.

---

## Quiz Objectives
The assessment evaluates your mastery of the following technical domains:
* **RAG Architecture**: The retrieval-augmentation-generation lifecycle.
* **Vector Mechanics**: The role of embeddings and cosine similarity in semantic search.
* **Algorithmic Efficiency**: Navigable Small Worlds (NSW) and the evolution of vector retrieval.
* **Knowledge Representation**: Identifying when to use graph structures versus flat vector stores.
* **Text Analytics**: Sentiment analysis and Named Entity Recognition (NER) workflows.
