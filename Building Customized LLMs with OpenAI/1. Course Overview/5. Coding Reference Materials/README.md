# Coding Reference Materials
### *Building Customized LLMs with OpenAI — Columbia Plus*

To succeed in the technical implementation phases of this course, you must be familiar with the specialized coding environments and library documentation used to build AI systems. This directory provides the essential links and resources required to set up your development workspace.

---

## Coding Environment
We utilize cloud-based tools to ensure consistency across all student projects and to provide access to necessary computing resources without local installation.

* **Google Colab**: The primary platform for writing and executing Python code. It provides a shared, interactive notebook environment.
    * [Introduction to Google Colab](https://colab.research.google.com/)
* **GitHub**: Used for version control and accessing course repositories.
    * [GitHub Quickstart Guide](https://docs.github.com/en/get-started/start-your-journey)

---

## Generative AI Resources
The AI landscape evolves rapidly. To ensure your applications use the most up-to-date syntax and best practices, we recommend bookmarking the official documentation for our core libraries:

* **OpenAI API Documentation**: The definitive guide for models like GPT-4o, DALL-E, and Whisper.
    * [OpenAI Python API Overview](https://platform.openai.com/docs/overview?lang=python)
* **LangChain Documentation**: The framework we use to "chain" LLMs with external data and tools.
    * [LangChain Tutorials](https://python.langchain.com/docs/tutorials/)
