# Module 2: ML Model

### *AI for Business — Columbia University*

This directory contains resources, notes, and assessments for **Module 2**, which focuses on the engine behind Artificial Intelligence: **Machine Learning (ML) Models**.

## Learning Objectives

In this module, the focus shifts from general AI concepts to the technical foundations of how systems learn from data. Key takeaways include:

* **Understanding ML Algorithms:** Deep dive into the primary algorithms used to build AI systems.
* **The Build Sequence:** Identifying the specific steps required to develop a functional ML model.
* **Defining "Real" AI:** Distinguishing between genuine machine learning capabilities and market hype.
* **Business Application:** Learning how to map these technical algorithms to specific business problems.

---

## Skills & Knowledge Acquired

* **Data Processing:** Introduction to handling structured data for model training.
* **Model Selection:** Understanding which key Machine Learning algorithms are appropriate for different business use cases.
* **Algorithmic Literacy:** Gaining the technical vocabulary needed to lead or participate in an AI team.
